# Sistem Informasi Absensi – Mahasiswa

## Deskripsi
Website Mahasiswa merupakan portal bagi mahasiswa untuk melihat informasi perkuliahan dan memantau kehadiran. Website ini memiliki tampilan yang sederhana dan menggunakan warna oranye serta krem untuk memberikan kesan yang menarik dan nyaman digunakan.

## Fitur
- **Beranda:** Menampilkan halaman utama portal mahasiswa.
- **Jadwal Kuliah:** Menampilkan informasi jadwal perkuliahan.
- **Riwayat Kehadiran:** Menampilkan riwayat absensi mahasiswa.
- **Lakukan Absensi:** Menyediakan formulir untuk simulasi pencatatan kehadiran.

## Teknologi
- HTML5 untuk struktur halaman.
- CSS3 untuk desain dan tata letak.
- JavaScript untuk interaksi dan validasi formulir.
- Visual Studio Code sebagai editor kode.

## Cara Menjalankan
1. Buka folder Mahasiswa di Visual Studio Code.
2. Buka file `index.html`.
3. Jalankan menggunakan Live Server atau browser.
4. Pilih menu yang tersedia untuk melihat jadwal, riwayat kehadiran, dan formulir absensi.

## Catatan
Website ini merupakan prototipe frontend untuk tugas UTS Pemrograman Web. Data mahasiswa dan riwayat kehadiran merupakan data contoh. Formulir absensi belum terhubung dengan server atau database.

## Kesimpulan
Website Mahasiswa dirancang untuk membantu mahasiswa mengakses informasi perkuliahan dan melihat riwayat kehadiran melalui portal yang mudah dipahami dan digunakan.
